# L'Etabli — Canal de distribution

Ce dépôt **public** héberge uniquement les fichiers de distribution de
L'Etabli (logiciel de gestion pour artisan encadreur) :

- `version.json` — manifeste de version lu par l'application pour détecter
  les mises à jour ;
- les **Releases** — binaires (AppImage Linux, etc.).

> Le **code source reste privé**. Ce dépôt ne contient aucun code, seulement
> les artefacts publics nécessaires au mécanisme de mise à jour automatique
> (qui fonctionne par requêtes anonymes et exige donc un hébergement public).
